# CS330
The project required me to divide the software design problem into smaller systems which included scene structure, object behavior, and interaction logic. The approach enabled me to develop reusable components because I could handle work through individual components instead of creating everything as one unit. The main design ability I acquired required me to create modular systems which included separate components for collision handling, rendering and object state updates.

The design process followed an iterative approach. I created a basic working scene, which I built upon by implementing physics-based movement and collision detection and object state changes. The milestones delivered both structural and operational improvements, which I achieved by updating previous code to meet the new project requirements. The iteration process enabled me to conduct tests which helped me find and solve issues that caused the system to operate incorrectly.
My development process now requires me to plan object interactions before I begin coding work. I now create the system through a gradual process which involves building small components and validating them before I write the entire system.

The course enhanced my understanding of computational graphics, which require mathematics and physics and programming languages to create visual content. The skills I obtained from the program will assist my future academic studies in advanced graphics and simulation and visualization courses. The skills I developed from this program will help me work in fields like game development and simulation systems and data visualization, which need organized visual displays for complicated systems.
